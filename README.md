# 六法ビューア

最新の六法（憲法・民法・商法・刑法・民事訴訟法・刑事訴訟法）を、「いま全体のどこを読んでいるか」（編 → 章 → 節 → 款 → 目 → 条）が常に見える形で読めるシングルページ Web アプリ。

**→ https://natsunooda.github.io/roppo-viewer/**

## 特徴

- **現在位置パンくず**: 読んでいる場所の 編›章›節›款›条（見出し）をスクロールに連動して常時表示
- **マップバー**: 法令全体を編ごとの色分け帯で表示、赤マーカー = 現在位置、クリックでジャンプ
- **階層目次**: 編〜目の全階層＋条数範囲。読み進めると自動で展開・ハイライト・追従
- **条数ジャンプ / 全文検索**: `709`・`第709条`・`398の22` で条へ、語句なら本文検索
- **常に最新**: e-Gov 法令 API v2 からブラウザが直接取得。新しい改正の施行を自動検知して更新
- 法令ごとに読書位置を記憶 / `#minpo/709` 形式の共有リンク / ダークモード対応

## 注意

- 表示は**本則のみ**（附則は省略）。正文の確認は [e-Gov 法令検索](https://laws.e-gov.go.jp/) へ
- 法令データの出典: e-Gov 法令 API（デジタル庁）

## 開発

`index.html` 単体（ビルド・依存なし）。ローカルでは `python3 -m http.server 8124 --directory .` などで配信して http://localhost:8124 を開く（`file://` 直開きでも動くが、読書位置の保存オリジンが変わる）。実装メモは [CLAUDE.md](CLAUDE.md)。
